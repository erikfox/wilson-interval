# Security policy

## Supported versions

Security fixes are released for the latest major version only.

| Version | Supported |
|---|---|
| 6.x | Yes |
| 5.x and earlier | No |

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub instead:

1. Go to the [Security tab](https://github.com/erikfox/wilson-interval/security) of this repository.
2. Select **Report a vulnerability** ([direct link](https://github.com/erikfox/wilson-interval/security/advisories/new)).
3. Describe the problem, the affected versions, and how to reproduce it.

If the report is confirmed, a fix is released as a new version and the advisory is published once it is available, crediting you unless you'd rather not be named.

Wrong statistical results that aren't a security problem can go in a [bug report](https://github.com/erikfox/wilson-interval/issues/new?template=bug_report.yml).
